## Recommended Order For New Users

1. Get the app running first
2. Try calling each endpoint one at a time
3. Build a JMeter flow with `1 user`
4. Add controllers such as `Transaction Controller`, `Throughput Controller`, `If Controller`
5. Then choose a test type such as `load`, `stress`, `spike`, `endurance`

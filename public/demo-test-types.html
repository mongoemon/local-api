Test Types And Thread Groups

หน้านี้ใช้เลือกว่าควร test แบบไหน และควรใช้ thread group อะไร

Thread Group Selection

Thread GroupBest ForUse When
Normalbaseline, debug, simple SLAเริ่มต้น, functional load, transaction เบื้องต้น
Concurrencystress, saturation, active sessionsอยากคุมจำนวน concurrent users
Steppingspike, thresholdอยากเห็นว่า fail ที่ step ไหน
Arrivalsteady traffic, open workloadอยากคุม request rate ต่อวินาที

Test Type Structures

Load Test

Thread Group or Concurrency Thread Group or Arrival Thread Group
└─ transaction flow or target endpoint

Spike Test

Stepping Thread Group or Concurrency Thread Group
└─ target endpoint or transaction flow

Endurance / Soak Test

Thread Group or Concurrency Thread Group or Arrival Thread Group
└─ target endpoint or demo flow

Stress Test

Concurrency Thread Group
└─ target endpoint or transaction flow

Quick Guidance

  • ถ้ายังใหม่ ให้เริ่มจาก Normal Thread Group
  • ถ้าจะหา limit ของ concurrent users ให้ใช้ Concurrency
  • ถ้าจะหา break point แบบเป็นขั้น ให้ใช้ Stepping
  • ถ้าจะคุม request rate ต่อวินาที ให้ใช้ Arrival

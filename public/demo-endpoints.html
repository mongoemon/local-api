Demo Endpoints

หน้านี้อธิบายแต่ละเส้น ก่อนสร้าง JMeter ให้เข้าใจ endpoint แต่ละตัวให้ชัดก่อน

Recommended Transaction Order

  1. GET /demo/context?search=mouse
  2. GET /demo/dashboard
  3. GET /demo/search?q=${demoSearchTerm}
  4. GET /demo/product/details?productId=${demoProductId}
  5. POST /demo/cart/add
  6. POST /demo/checkout
  7. GET /demo/order/status?orderId=${demoOrderId}

Proof Of Concept Static Flow

1. GET /demo/dashboard
2. GET /demo/search?q=mouse
3. GET /demo/product/details?productId=sku-101
4. POST /demo/cart/add
   { "cartId": "demo-cart", "productId": "sku-101", "quantity": 1 }
5. POST /demo/checkout
   { "cartId": "demo-cart", "customerId": "demo-user-01" }
6. Copy orderId from checkout response
7. GET /demo/order/status?orderId=<copied-order-id>

Variable Structure

ตัวแปรทุกตัวมาจาก response ของ /demo/context หรือ /demo/checkout ตั้งชื่อให้สื่อว่าเอามาจากไหนและจะถูกใช้ต่อที่ไหน
VariableSource (JSON path)Use In
demoSearchTerm/demo/context → $.searchTermGET /demo/search?q=${demoSearchTerm}
demoProductId/demo/context → $.recommendedProductIdGET /demo/product/details, POST /demo/cart/add
demoCartId/demo/context → $.cartIdPOST /demo/cart/add, POST /demo/checkout
demoShopperId/demo/context → $.shopperIdPOST /demo/checkout
demoOrderId/demo/checkout → $.orderIdGET /demo/order/status?orderId=${demoOrderId}

What To Learn Here

  • เส้นไหนต้องส่ง query parameter
  • เส้นไหนต้องส่ง JSON body
  • เส้นไหนต้องใช้ค่าจาก response ก่อนหน้า (variable chaining)
  • เมื่อไรควรใช้ค่าคงที่ และเมื่อไรควรใช้ตัวแปร
สำหรับการตั้งค่า User Defined Variables, HTTP Header Manager, และ JSON Extractor ใน JMeter ดูที่ JMeter Guide
